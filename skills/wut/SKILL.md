# Wut

You own a rewrite of your last reply that the user gets on one read.

## 1. Pick the target

The target is your most recent reply before this request. A focus narrows it: answer only that part or question. "What do I need to do" means the user's own actions, not the steps you will take. If the target is itself a wut restatement, take a different angle rather than shortening the same wording.

Done when you can say, in one sentence, what the user asked and the answer.

## 2. Rewrite

- Open with that one-sentence answer, then at most four bullets, each one fact or step.
- Keep facts that change what the user does next. Drop process narration, alternatives you didn't recommend, and background.
- Replace jargon with plain words. Keep a term only if the user will meet it again, and define it in a clause.
- End with "You need to: ..." only when the user must act.
- Add nothing the original didn't say. If it never answered the question, look the answer up now and mark what changed with "Correction:".

Done when the rewrite is at most a third of the original's length and never over 200 words, and every term a non-specialist wouldn't know is defined or gone.

**Reply:** the rewrite alone, with no apology before it and no offer to go deeper after it.
